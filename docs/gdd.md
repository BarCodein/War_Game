# War of Dots 游戏设计文档（GDD）

> 本文档将 `REQUIREMENTS.md` §8 的「待确认事项」逐项落为具体设计。**所有数值与公式均为「暂定」默认值**，需团队确认后方可改为「已确认」并作为最终实现标准（`REQUIREMENTS.md` §1）。

## 1. 术语表

| 术语 | 定义 |
|---|---|
| 单位 | 地图上一个可指挥的圆点实体，分轻型、重型两类 |
| 阵营 | blue（玩家）/ red（敌方），城市与单位均归属某一阵营 |
| 城市 | 可被占领的建筑，提供生产、补给与恢复 |
| 补给 | 每座己方城市可维持的单位数量上限（默认 5） |
| 占领 | 己方单位在城市附近持续积累占领进度直至城市易主 |
| 士气 | 0–100 的单位状态值，低士气削弱单位，归零溃逃 |
| 溃逃 | 士气归零后单位不受指挥向己方城市撤退；无法撤退则投降移除 |
| 战争迷雾 | 视野三态：当前可见 / 已探索但不可见 / 从未探索 |
| 最后已知位置 | 敌军离开视野后留下的灰色虚影标记 |
| 交战距离 | 单位自动攻击敌对单位的距离（即攻击距离） |
| 命令接口 | 人类输入、脚本敌军与未来 AI 共用的统一下令通道 |

## 2. 核心循环

观察 → 决策 → 下令（选择/移动/攻击）→ 模拟推进（战斗、士气、补给、占领）→ 迷雾与状态反馈 → 胜负判定。

单局时长为小型遭遇战规模（约 5–15 分钟），教学关卡引导玩家完成完整闭环。

## 3. 单位设计（§8-2）

| 属性 | 轻型单位 | 重型单位 |
|---|---|---|
| 生命值 | 60 | 120 |
| 伤害 | 8 | 16 |
| 攻击间隔 | 1.0 s | 1.6 s |
| 攻击距离 | 40 | 55 |
| 移动速度 | 90 px/s | 55 px/s |
| 单位半径 | 10 | 14 |
| 视野半径 | 140 | 160 |
| 理论 DPS | 8 | 10 |

**设计意图**：重型单位正面更强（2 倍血量、更高 DPS），但机动性差；轻型单位负责侦察、占领与包抄，两类单位占领贡献相同，由数量决定占领速度。

## 4. 战斗规则（§8-2）

- 敌我单位**足够接近（圆点视觉接触）**后**自动交战**，无需玩家下令——交战距离为「双方半径和 + 容忍值（`config.combat.contactTolerance`）」，比按攻击距离更严格；超出接触距离不战斗。
- **目标选择**：优先攻击当前目标直至其死亡，否则选取接触范围内最近的敌人；无目标时恢复行军/驻守。
- **伤害公式**：`最终伤害 = 基础伤害 × 防御者地形修正`（地形修正见 §5）。
- **攻击间隔**：每单位独立冷却计时，首次接触立即攻击。
- **碰撞规则**（暂定）：单位之间为软排斥（无硬碰撞），互不阻挡移动；单位不可进入水域。
- **攻击前进/脱离战斗**：move 与 attackMove 均沿**预定路线**行军（下令时整条规划最短路径，绕开水域）；途中接触敌军即停下交战，敌军离开或清空后沿路线继续。红方脚本只使用 attackMove/hold，行为一致。

## 5. 地形（§8-2、§8-5）

| 地形 | 通行 | 移动倍率 | 防御修正 | 视野规则 |
|---|---|---|---|---|
| 平原 | 可 | 1.0 | 1.0 | 正常 |
| 森林 | 可 | 0.6 | 0.85 | 位于森林中的敌军，仅当己方单位距其 ≤60 时可见 |
| 水域 | 不可 | — | — | 正常（无实体可藏） |
| 桥梁 | 可 | 1.0 | 0.9 | 正常 |

- 逻辑网格：格子 20 px，编码 `0 平原 / 1 森林 / 2 水域 / 3 桥梁`，用于通行性、寻路成本与视野阻挡。
- **移动与寻路（暂定）**：右键指令默认直线行进，路径与水域相交时在逻辑网格上 A* 绕行并缓存路径；批量单位共享路径缓存以控制开销。

## 6. 士气系统（§8-1）

范围 0–100，初始 80。

**每秒修正（可叠加）**：

| 因素 | 修正 |
|---|---|
| 附近友军（≤60 px） | +2 /s |
| 附近己方城市（≤120 px） | +5 /s |
| 补给充足 | +1 /s |
| 补给不足 | −2 /s |
| 交战中（正在被攻击） | −1 /s（持续围攻需 ~80 s 才溃逃，保证攻城可行） |
| 附近友军阵亡（≤100 px，阵亡瞬间） | −10 |

**阈值与效果**：

| 士气区间 | 状态 | 效果 |
|---|---|---|
| ≥60 | 正常 | 无 |
| 30–59 | 削弱 | 伤害 ×0.75，速度 ×0.85 |
| 1–29 | 动摇 | 伤害 ×0.5，速度 ×0.7 |
| 0 | 溃逃 | 见下 |

**溃逃与投降（暂定）**：士气归零后单位不受指挥，向最近己方城市全速撤退，期间士气 +8 /s；恢复到 ≥20 时停止溃逃。若 5 秒内移动无进展（被困），或无己方城市可退，则**投降移除**。撤退期间受到攻击时 −3 /s 修正仍生效。

**反馈方式**：士气条 <60 变黄、<30 变红；溃逃单位外圈白色闪烁；编队列表显示状态标签（正常/削弱/动摇/溃逃）。

## 7. 城市系统（§8-3、§8-4）

**占领（暂定）**：

- 占领半径 60 px；城市范围内每名己方单位贡献 **5% /s**，多单位叠加，上限 **15% /s**（3 个单位即达上限）。
- **争夺判定**：范围内存在敌方存活单位时，占领进度冻结。
- 己方单位全部离开后，进度以 **3% /s** 衰减回 0。
- 进度达到 100% 时城市变更阵营（从 0 重新计数，供再占领）。

**生产（暂定）**：MVP 采用**自动生产**——每座己方城市每 **12 s** 生产 1 个轻型单位，出生在城市旁；当该城补给容量已满，或**城市被围攻（敌方单位进入占领半径）时暂停生产**，保证攻城战可决出胜负。玩家配置生产（队列、兵种选择）不在 MVP 范围，作为后续扩展。原型中的「钢材/能源/情报」资源面板与快速部署按钮为占位设计，MVP 移除（无经济系统）。

**恢复（暂定）**：己方城市 120 px 内的己方单位，生命 +3 /s，士气 +5 /s（与 §6 城市士气修正叠加）。

## 8. 补给系统

- 每座己方城市提供 **5** 个单位的补给容量；每名己方单位按就近原则分配到一座城市。
- 超出容量的单位判定为**补给不足**：生命 −1 /s（损耗），士气 −2 /s。
- 补给归属在单位移动后按就近原则重新分配。

## 9. 战争迷雾（§8-5）

- 可见区域 = 己方单位视野圆 ∪ 己方城市视野圆（城市视野 180）。
- **三态**：当前可见 / 已探索但不可见 / 从未探索。当前可见正常渲染；未探索与已探索但不可见**统一叠加浅色迷雾**（地形保持可见，仅以浅雾标识「当前不在视野」），不再有深色遮蔽。
- 森林视野阻挡：森林中的敌军仅在 60 px 内可见（§5）。
- **不可见敌军不显示任何实时状态**（位置、血量、士气、编队）；离开视野时在其最后已知位置显示灰色虚影标记，重新目视后更新。
- 原型中的「实际控制线」为视觉表现，暂定保留（非需求项，基于双方单位位置插值，实现成本低）。

## 10. 教学战役关卡：断裂峡谷（§8-6）

**地图**（1280×720）：蓝军城市 A 位于西南，红军城市 B（北方信标）位于东北；河流自西向东横贯中部，中央一座桥梁；两岸散布森林。

**初始兵力**：蓝军 3 轻型 + 1 重型，集结于城市 A；红军 2 轻型 + 2 重型驻守城市 B 周边（驻守半径 80 px）。

**红军脚本**：

1. 开局：全部单位驻守城市 B。
2. 第 60 s：东侧出生点增援 2 个轻型单位，向城市 B 移动。
3. 触发：蓝军任一单位越过地图中线（x = 640）时，守军向最近的蓝军单位进攻。
4. 蓝军覆灭后，红军向蓝军城市 A 进军并占领（保证失败条件可达）。

**平衡验证**：headless 实测（模拟合理玩家：每 5 s 全军 attackMove 信标）蓝军 45 s 获胜，结束时蓝军存活 5（含城市生产增援）；兵力配比无需额外调整。

**任务链**（右侧任务面板逐条点亮）：

1. 「建立前线基地」— 教学：框选全部单位（开局自动完成）。
2. 「向桥头推进」— 教学：指挥所选单位移动至桥头区域（完成一次移动指令即通过）。
3. 「清除信标周边敌军」— 信标（城市 B）周边 200 px 内无红军。
4. 「占领北方信标」— 城市 B 占领进度达到 100%（即完成占领）。

**胜负条件**：

- 胜利：占领全部敌方城市（本关即城市 B）。
- 失败：蓝军全部单位阵亡且蓝军已无可生产城市（城市 A 被占领）。
- 达成条件即弹出结算界面，可重新开始。

## 11. UI 方案

沿用原型的军事风格 HUD，调整如下：

- **移除**：资源条（钢材/能源/情报）、快速部署按钮、基地护盾状态（无经济系统，见 §7）。
- **顶栏**：暂停/继续、声音开关（保留）。
- **左栏**：编队列表（血量、士气、状态标签）；城市状态卡（占领进度、生产倒计时、补给占用 x/5）。
- **中央**：战场画布 + 操作提示 + toast 通知；底部图例与坐标。
- **右栏**：任务进度面板、战场通讯（事件日志）、快捷键说明。
- **操作**：左键单选、拖动框选、Shift 增减选、右键移动/攻击移动/攻击指定单位、从已选单位拖出轨迹（多路径点移动，暂定保留）；空格暂停，Esc 取消选择。
- **反馈文本**全部走 i18n 模块，中文优先。
