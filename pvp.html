本地怎么跑：开两个终端 —— npm run server（Node，127.0.0.1:3001） 与 npm run dev（Vite），然后打开 http://localhost:5173/pvp.html。 再开一个无痕窗口注册另一个账号，就能自己和自己对战（两个浏览器上下文）。
一个进程验证（不用 Nginx）：npm run build 后 PVP_SERVE_STATIC=1 npm run server（Windows：$env:PVP_SERVE_STATIC=1; npm run server）， 打开 http://127.0.0.1:3001/pvp.html。
线上：Nginx 反代 /api 与 /socket.io 到 127.0.0.1:3001 后，打开 http://<服务器IP>/pvp.html。
